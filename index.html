MOVE TO ANOTHER COMPUTER

三步驟，帶走你的 skill

01 / DOWNLOAD下載並解壓縮

選擇單一技能或整包下載。解壓縮後，保留以 skill 名稱命名的資料夾與其中全部檔案。

02 / INSTALL放進個人 skills 目錄

此電腦使用 ~/.codex/skills。若新電腦的 Codex 版本使用 ~/.agents/skills，請依該版本文件放置。自訂 CODEX_HOME 時使用其 skills 目錄。已有同名資料夾請先備份。

03 / USE開新對話，指定使用

在 Codex 新對話輸入「使用 pic，把這段教材做成圖表」等指令。確認新電腦已提供該技能需要的工具。

下載按鈕會取得 ZIP；瀏覽器不會自動安裝技能。圖片生成、外掛、帳號授權與 Python 套件需在新電腦另行設定。
